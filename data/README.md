# Data

The raw CSV files are not stored in this repository because of their size.

Download them from Kaggle:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Original tables: customers, orders, order_items, order_payments,
order_reviews, products, sellers, geolocation, category_translation.

The cleaned and modeled data is embedded in `powerbi/Olist_Dashboard.pbix`.
